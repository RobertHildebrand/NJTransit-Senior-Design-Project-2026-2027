# NTD data for the River LINE (Hybrid Rail, mode YR, NTD ID 20080)
Retrieved 2026-09-28 from data.transportation.gov (Socrata API), transcribed from API output.
- Monthly Module Adjusted Data Release (dataset 8bui-9xvu): https://data.transportation.gov/resource/8bui-9xvu.json?ntd_id=20080&mode=YR
- 2022-2024 NTD Annual Data - Metrics (dataset ekg5-frzt): https://data.transportation.gov/resource/ekg5-frzt.json?ntd_id=20080&mode=YR
The River LINE is reported as Hybrid Rail (YR), not light rail. PT (purchased transportation) through Feb 2026; DO (directly operated) from Feb 2026 after NJ TRANSIT took over from Alstom.
Annual metrics are NTD report years (NJ TRANSIT fiscal years ending June 30); monthly/annual UPT file is calendar months. 2026 is partial (Jan-Jul).
