# NJ TRANSIT performance data (downloaded by R. Hildebrand, 2026-09-28)
Source: NJ TRANSIT performance data download page https://www.njtransit.com/performance-data-download
- njt_lightrail_mdbf_by_line_monthly.csv: mean distance between failures (miles) by light rail line, Jan 2017-Aug 2026 (from LIGHTRAIL_MDBF_DATA.csv). Values move smoothly, so they appear to be a rolling average; the definition is not stated in the file.
- njt_lightrail_otp_monthly_all_lines.csv: on-time performance, all light rail lines combined, Jan 2017-Aug 2026 (from LIGHTRAIL_OTP_DATA.csv). Not by line.
Originals: docs_downloaded/A_performance_and_ntd/D01, D02.
