\section*{Update: what the team downloaded (September 28, 2026)}
A team member downloaded 22 files. They are now in \texttt{RiverLine-Team22/docs\_downloaded/}, sorted into subfolders by section of the table below and renamed by ID. Three duplicate copies were discarded. The main results, now in the background report and in \texttt{data\_public/}:

\begin{itemize}
\item \textbf{D02 (failures).} NJ TRANSIT's monthly River LINE miles between failures, January 2017 to August 2026. The series fell to 2{,}377 miles (September 2025) and recovered to about 3{,}700 by mid-2026. Saved in \texttt{data\_public/njt\_performance/}.
\item \textbf{D06 (satisfaction surveys).} River LINE overall satisfaction by wave: 6.6 (Spring 2022), falling to 5.9 (Spring 2025), then 6.8 (Fall 2025). It was the lowest light rail line in every wave until Fall 2025. Top-ten attribute scores were also extracted. Saved in \texttt{data\_public/njt\_survey/}.
\item \textbf{D05 and D04 (NTD cost history).} River LINE operating cost, fares, and service for 2015--2024, and the 2019 agency profile.
\item \textbf{D09 and D10 (board agendas).}
  \begin{itemize}
  \item Confirmed ``River LINE insourcing: 94 FTE, \$3.9m.''
  \item Found board item 2511-51 (November 12, 2025). It records a termination for convenience ``due to performance concerns,'' the February 14, 2026 transfer date, and the new subsidiary NJ TRANSIT Southern Light Rail, Inc.
  \end{itemize}
\item \textbf{D19 (NJDOT safety oversight appendix).} Burlington City Yard holds 2 cars and the Trenton layover holds 8. The line has 72 grade crossings and 23 bridges, and trains are limited to 2 cars. It gives no siding mileposts.
\item \textbf{D17 (FRA docket).} The file is a 2007 e-mail setting a 25\,mph limit at the Farnsworth Avenue crossing, not the Temporal Separation Plan, which is still needed.
\end{itemize}

\paragraph{Still most useful to get:}
\begin{itemize}
\item River LINE-only on-time data; the public file is all light rail.
\item The 2003 Temporal Separation Plan.
\item Board agendas from September 2025 to February 2026, to find the Kinkisharyo contract.
\item The official track chart with siding limits (Data Request).
\item Post-takeover boardings by station.
\end{itemize}

\paragraph{Why these were missing.} Our research tools could not open these files. Most are PDFs on \texttt{content.njtransit.com}, which blocks automated access in its robots file. Others are JavaScript dashboards, paywalled articles, or PDFs whose text did not extract. A team member can download almost all of them in an ordinary web browser.
\begin{itemize}
\item Save each file to \texttt{RiverLine-Team22/docs\_downloaded/}, using the ID in the first column as the file-name prefix (e.g.\ \texttt{D01\_Fall2024\_survey.pdf}).
\item Items marked \emph{OPRA} are not public. Request them from NJ TRANSIT under New Jersey's Open Public Records Act, through NJ TRANSIT's records-request page on njtransit.com (search ``OPRA'') or the client contact. Several overlap with our Data Request.
\end{itemize}

\paragraph{Priority.}
\begin{itemize}
\item \Hi: feeds our models or the client report directly.
\item \Md: useful context.
\item \Lo: nice to have.
\end{itemize}
